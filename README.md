# 🌐 IP Address Information Tool

A Python-based networking utility that analyzes IPv4 and IPv6 addresses and provides detailed network information.

## 🚀 Features

- ✅ IPv4 / IPv6 Detection
- ✅ CIDR Prefix Detection
- ✅ Subnet Mask Calculation
- ✅ Network Address
- ✅ Broadcast Address
- ✅ Total Address Calculation
- ✅ Usable Host Calculation
- ✅ First Host Address
- ✅ Last Host Address
- ✅ Private / Public IP Detection
- ✅ Loopback Detection
- ✅ Multicast Detection
- ✅ Link-Local Detection
- ✅ IPv4 Class Detection
- ✅ `/31` Point-to-Point Network Support
- ✅ `/32` Single Host Support
- ✅ Input Validation & Error Handling
- ✅ Interactive CLI Menu

## 🛠️ Technologies

- Python 3
- `ipaddress` module
- Command Line Interface (CLI)
